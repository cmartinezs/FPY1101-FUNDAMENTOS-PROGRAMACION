# Leccion 08 - Matrices y Listas Asociadas

Esta leccion profundiza el uso de listas en Python mediante dos ideas importantes: matrices como listas de listas y listas asociadas como colecciones relacionadas por posicion.

## Idea central

Una matriz permite representar informacion organizada en filas y columnas, como un tablero de ajedrez. Las listas asociadas permiten guardar datos relacionados en listas separadas usando el mismo indice, como las butacas disponibles, ocupadas y reservadas de un cine.
